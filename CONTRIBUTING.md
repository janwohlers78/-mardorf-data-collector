# Contribution policy

This repository is a public acquisition-only companion for a private forecasting system.

External code contributions are not accepted. Pull requests and issues from accounts other than the repository owner are automatically closed. The repository is published only so the source-acquisition workload can run transparently on GitHub-hosted public runners.

Forks and local clones are independent copies. They do not receive this repository's Actions secrets, credentials, private target data, or authorization to write to the private forecasting repository.

Security-sensitive reports should not include credentials, tokens, private repository data, or copied workflow logs containing sensitive values.
